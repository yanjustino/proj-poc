# Geração de artefatos

O mapa de artefatos mostra o que já está pronto, o que pode ser gerado e quais documentos ainda aguardam dependências.

<AppMockup screen="artefatos" />

## Estados do mapa

| Estado | Significado |
| --- | --- |
| **Disponível** | Todas as dependências obrigatórias existem. |
| **Gerando** | Há uma execução ativa acompanhada pela interface. |
| **Pronto** | O documento foi aprovado e persistido. |
| **Aguardando dependências** | Um ou mais artefatos anteriores ainda faltam. |

As coleções — como ADRs, diagramas, features e histórias — se expandem em itens individuais depois da geração.

## Contexto usado pelo LLM

O Senpai usa:

- a wiki do próprio work-item;
- os artefatos anteriores exigidos pelo workflow;
- parâmetros específicos da ação, como o identificador de uma feature;
- orientações de uma rodada de revisão, quando existirem.

Para os novos artefatos, o contexto entre gerações vem preferencialmente do JSON estruturado. O HTML continua sendo produzido para leitura e exportação. Projetos antigos que têm somente HTML usam essa versão como fallback.

## Execuções em segundo plano

Você pode trocar de aba enquanto uma geração está em andamento. A interface mantém o acompanhamento da execução e volta a associá-la ao cartão correspondente quando necessário.

Algumas ações em lote podem executar trabalhos independentes em paralelo, como a geração das histórias pendentes de diferentes features.

## Diagramas

Documentos Mermaid são renderizados no aplicativo e preparados para visualização offline. Assim, o material exportado não depende de um serviço externo para exibir o diagrama.
